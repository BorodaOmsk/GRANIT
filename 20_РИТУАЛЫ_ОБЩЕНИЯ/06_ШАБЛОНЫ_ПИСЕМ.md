# Шаблоны писем и повесток

Готовые к использованию тексты для ежедневной переписки с заказчиком. Копируйте, подставляйте данные, отправляйте. Все шаблоны следуют принципу «нет письма — нет решения»: любая устная договорённость закрепляется письмом.

---

## 1. Протокол установочной встречи (ритуал старта)

```
Тема: Протокол установочной встречи по проекту [название] от [дата]

Коллеги, спасибо за встречу. Фиксирую договорённости:

1. КУРАТОР ПРОЕКТА со стороны заказчика: [ФИО, должность, контакты].
   Все запросы и пожелания по проекту направляются через куратора.

2. ЕДИНОЕ ОКНО ИЗМЕНЕНИЙ: любая внеплановая задача регистрируется
   через менеджера изменений и рассматривается на CCB. Это гарантирует,
   что ни одна задача не потеряется и получит корректный приоритет.

3. РИТМ ПРОЕКТА:
   - Совет по изменениям (CCB): [день] в [время], еженедельно.
   - Демо результата: в конце каждой итерации, [день].
   - Статус-отчёт: [день] до [время], письменно.

4. БУФЕР под внеплановые задачи: [X]% ёмкости команды в каждой итерации.

5. Изменения объёма и сроков оформляются решением CCB под протокол,
   при необходимости — дополнительным соглашением к контракту.

Прошу подтвердить, что всё зафиксировано верно.

С уважением, [ФИО, РП]
```

---

## 2. Приглашение на CCB с повесткой

```
Тема: Совет по изменениям № [N] — [дата], [время]

[Имя куратора], добрый день!

Приглашаю на еженедельный Совет по изменениям.

ПОВЕСТКА:
1. Состояние буфера текущей итерации.
2. Новые запросы за неделю — [кол-во], с оценкой влияния.
3. Решения по маршрутам (буфер / следующий инкремент / изменение контракта).
4. Приоритизация очереди буфера.
5. Риски, требующие вашего решения: [краткий список].

Материалы (реестр изменений, карточки влияния) во вложении.
Формат: [ссылка/место], [длительность] мин.

С уважением, [ФИО, РП]
```

## 3. Регистрация вброса (подтверждение приёма)

```
Тема: Запрос [краткое название] зарегистрирован — CH-[NNN]

[Имя], добрый день!

Ваш запрос принят и зарегистрирован в реестре изменений под № CH-[NNN].

Суть (как я понял): [формулировка своими словами].
Заявленная срочность: [P1/P2/P3].

Дальнейшие шаги: подготовим оценку влияния и вынесем на CCB [дата].
По итогам вернусь с вариантами по срокам.

Если я неверно понял суть — поправьте, пожалуйста.

С уважением, [ФИО]
```

---

## 4. Карточка влияния с вариантами (ответ на вброс)

```
Тема: Оценка запроса CH-[NNN] — варианты решения

[Имя], добрый день!

Оценили запрос «[название]». Трудозатраты: ~[X] [SP/дней].

Варианты встраивания:
  А) В буфер этой итерации — сдвигается задача [Y] на следующую итерацию.
  Б) В следующий инкремент — без сдвига текущих обязательств.
  В) Срочно и сверх объёма — оформляем допсоглашение,
     веха №[N] сдвигается на [M] дней.

Наша рекомендация: [вариант] — потому что [обоснование].

Какой вариант выбираете? Зафиксирую решение на CCB.

С уважением, [ФИО]
```

## 5. Подтверждение решения CCB

```
Тема: Решения CCB № [N] от [дата]

Коллеги, по итогам Совета по изменениям зафиксированы решения:

  CH-[NNN] «[название]» → [маршрут: буфер / инкремент / допсоглашение / отклонено]
  CH-[NNN] «[название]» → [маршрут]

Влияние на вехи: [есть сдвиг вехи №N на M дней / без изменений].
Требуются допсоглашения: [нет / да, по CH-NNN].

Протокол во вложении. Прошу подтвердить согласие.

С уважением, [ФИО, РП]
```

## 6. Еженедельный статус-отчёт

```
Тема: Статус проекта [название] — неделя [N] ([даты])

1. ПРОГРЕСС ПО ВЕХЕ №[N]: [🟢 в графике / 🟡 напряжённо / 🔴 риск срыва]
   [одна строка комментария]

2. СДЕЛАНО ЗА НЕДЕЛЮ:
   - [пункт]
   - [пункт]

3. ПЛАНЫ НА СЛЕДУЮЩУЮ НЕДЕЛЮ:
   - [пункт]

4. ЗАПРОСЫ ЗА НЕДЕЛЮ: поступило [X], в буфер [Y], в след. инкремент [Z].

5. РАСХОД БУФЕРА: [использовано] из [всего] [SP/дней].

6. НУЖНО ОТ ВАС: [решение по CH-NNN до дата / нет открытых вопросов].

С уважением, [ФИО, РП]
```

## 7. Перенаправление запроса от «другого начальника»

```
Тема: Ваш запрос по проекту [название]

[Имя], добрый день!

Спасибо за запрос — он понятен и важен. Чтобы он получил правильный
приоритет и не конфликтовал с уже согласованным планом, проведём его
через [ФИО куратора], который сводит приоритеты вашей стороны воедино.

С вашего позволения передам ему формулировку, чтобы запрос не потерялся
и попал в ближайший Совет по изменениям.

С уважением, [ФИО]
```

## 8. Сообщение о риске срыва вехи

```
Тема: ВАЖНО: риск по вехе №[N] — требуется решение

[Имя куратора], добрый день!

Сообщаю заранее, пока есть время на манёвр.

СИТУАЦИЯ: веха №[N] ([дата приёмки]) под риском срыва.
ПРИЧИНА: [конкретная причина].
ВЛИЯНИЕ: [что именно не успеваем и почему].

ВАРИАНТЫ:
  А) [вариант с последствиями]
  Б) [вариант с последствиями]
  В) [вариант с последствиями]

Предлагаю обсудить на CCB [дата/экстренно]. Материалы во вложении.

С уважением, [ФИО, РП]
```

## 9. Напоминание о зависшем решении заказчика

```
Тема: Ожидаем ваше решение по [вопрос] — влияет на сроки

[Имя], добрый день!

Напоминаю: ждём вашего решения по [вопрос/CH-NNN] с [дата].

Каждый день ожидания сдвигает старт задачи [X] и приближает риск
по вехе №[N]. Просьба принять решение до [дата] — иначе вынуждены
зафиксировать сдвиг срока не по нашей вине.

Готов созвониться, если нужно обсудить варианты.

С уважением, [ФИО, РП]
```

---

## Правила пользования шаблонами

1. **Отправляйте в тот же день**, пока договорённость свежа.
2. **Пишите коротко** — заказчик не читает длинные письма.
3. **Всегда просите подтверждение** по решениям об объёме/сроках.
4. **Сохраняйте переписку** — это доказательная база (журнал согласований).
5. Связанные артефакты и полные таблицы — в [09_ШАБЛОНЫ методологии](../09_ШАБЛОНЫ.md).
```
